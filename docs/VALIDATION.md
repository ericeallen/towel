# How Towel is validated

[Documentation index](README.md)

This page will summarize, for the current release, the tests, the fuzzing and
the run over open-source projects that each release must pass, with a link to
the full evidence. It is being written for Towel 2.0. Until it is, the
[production readiness report](maintainers/PRODUCTION_READINESS.md) records each
release's validation in full.
