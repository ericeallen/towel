[Documentation index](README.md)

This page will list the common reasons Towel declines an extraction, each with
what it means for your code and what you can do about it, and show how
`towel preview --explain` names the reason for a particular pair. It is being
written for Towel 2.0. Until it is, the complete catalogue is in
[Known limitations](KNOWN_LIMITATIONS.md).
