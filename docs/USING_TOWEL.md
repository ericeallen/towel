# Using Towel on a project

[Documentation index](README.md)

This page will walk through a real project: working on a branch, choosing what
to scan, bounding a long run, reviewing a large diff, keeping some extractions
and dropping others, naming the helpers and running your tests. It is being
written for Towel 2.0. Until it is, the [quick start](QUICKSTART.md) shows the
whole cycle on a small example and the [command reference](CLI_GUIDE.md) covers
each option.
