# Gallery sources

Unmodified modules from published releases, which docs/GALLERY.md runs Towel on
(tests/test_documentation_examples.py). Each directory holds the project's own
licence. The `.txt` suffix keeps the repository's checks off them; the test
copies each to its `.py` name.
