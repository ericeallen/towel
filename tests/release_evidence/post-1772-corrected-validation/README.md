# Completed corrected-source validation evidence

These immutable records belong to frozen commit
`3af8c4bfe8acd56c204f5e31c7cf80f4f028b654`. They include the complete corrected
corpus, serial Linux interpreter matrix, transformed native suite, fuzzing,
artifact and clean-install checks, and explicit reviews of every exception.
The [report](../../../docs/proposals/next-validation-final.md) gives the actual
platforms, resources, timings and limits. All artifacts still numbered 1.772
are validation only and must not be uploaded.

Gzip files decompress to byte-exact originals. The pinned provenance manifest
records their paths, byte lengths and SHA-256 values. The tests verify that
inventory and compare documentary claims to the retained observations. They
never execute retained scripts. Actual artifacts and source trees remain in
the external archive recorded by the manifest; offline tests cannot rehash
omitted files. The release-evidence verifier independently checks those actual
archives and source bytes when given the portable external bundle.

Historical failures are deliberate evidence: the prior OOM, the original
queue stop, 33 nonzero baselines, three untyped fallbacks, five safe refusals,
and Pyparsing's traceback reflection cases must not be relabelled successful
extractions or green upstream CI. Current Towel's corpus baseline completed
with 18 failures; a separate current-source matrix validates the candidate.
Later documentation tests are not included in the frozen suite counts.

Do not edit these observations or loosen their intent to match a later release.
A new run needs a new source identity and evidence set. A correction requires
original instrument output and an explicit explanation. Observed machine RAM
is not a minimum requirement; elapsed validation time is not a speedup claim.
